## Tech Stack (Locked)

- Next.js 15 (App Router) + TypeScript
- Tailwind CSS + Shadcn/UI
- TanStack Query
- Zustand
- React Hook Form + Zod
- Axios

## Getting Started

```bash
pnpm install
cp .env.example .env.local
pnpm dev
```
